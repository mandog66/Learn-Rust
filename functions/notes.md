# Note

## 函式簽名(Signatures)

* 包含三個部分 :
    1. 函式名稱
    2. 參數名稱與型別
    3. 回傳型別

* 功能 :
    1. 型別檢查 : 編譯器能在編譯時知道傳入或回傳的型別是否有誤
    2. 錯誤提示 : 編譯器可以顯示明確的除錯資訊
    3. 介面維護 : 可以方便知道函式呼叫方式

> [!NOTE]
> 函式簽名不支援於函式多載(Overloading)，一般來說會用泛型(Generics)來解決

## 比較陳述式(statements)和表達式(expression)

### 陳述式(statements)

* 是執行某些動作的指令，不會有回傳數值(隱式回傳`()`)
* 結尾會有分號
* 不能賦值給另一個變數

```Rust
let num1 = 100; // 陳述式，結尾有分號
let num1 = (let num2 = 100); // Error
```

### 表達式(expression)

* 是計算並產生數值的**程式片段**，有回傳數值
* 結尾沒有分號
* 能賦值給另一個變數

```Rust
let a = {
    let b = 1;
    b // 沒有分號
}; // a會被b賦值
```

> [!IMPORTANT]
> Rust 是基於**表達式**的語言。幾乎所有區塊(`if`、作用域區塊`{}`)，都可以計算出數值並賦值給變數。
> 在其他語言，例如 Python 在賦值給變數時就要把指令寫完整
>
> ```Python
> if a >= 5:
>   result = "大於等於"
> else:
>   result =  "小於"
> ```
>
> 在 Rust 中，`if`能夠算出數值並賦值給變數
>
> ```Rust
> let result = if a >= 5 { "大於等於" } else { "小於" };
> ```
