# Note

## 常數(Constants)

* 常數名稱習慣全部**大寫**並用**底線**區隔
* 宣告時**必須**明確定義資料型別
* 可以在**任何**範圍內宣告，包含全域
* **必須**使用常數表達式定義

>[!NOTE]
>常數是編譯時期就會被計算出來，所以不能用只能在執行時才會知道的數值，像是使用者輸入

## 遮蔽(Shadowing)

* 遮蔽會佔據原本變數的使用權，直到離開作用域
* 允許宣告時變更資料型別

```RUST
let num = 100;
println!("num is {}", num); // 100
{
    // 遮蔽佔據
    let num = num * 2;
    println!("num is {}", num); // 200
}
// 遮蔽離開內部作用域變回原本數值
println!("num is {}", num); // 100
```
