# Learn-Rust

Rust程式設計語言練習

## 建立一個新工作區

* 在根目錄手動新增一個檔案，取名`Cargo.toml`並將以下內容寫入:

    ```toml
    [workspace]
    # 設定工作區的依賴解析器邏輯，確保所有專案對套件功能的處理方式一致
    resolver = "2"
    # 登記所有屬於這個工作區的子專案資料夾名稱
    members = []
    ```

> [!NOTE]
> **建立工作區(Workspace)兩個核心優點**
>
> 1. **環境一致性** : 確保所有子專案的依賴解析器(resolver)保持一致
> 2. **節省儲存空間** : 所有子專案共用根目錄的 `./target` 資料夾，避免重複編譯相同的套件，減少儲存空間也加快編譯速度

## 建立一個新專案(Packge)

* 在工作區的根目錄開啟終端機並輸入指令:

    ```powershell
    # 建立子專案
    cargo new project_name
    ```

> [!IMPORTANT]
> 新專案產生後檢查 `members = []` 的括號中專案名稱有沒有被加入

> [!TIP]
> 如果不想每次手動編輯，可以將成員設定為萬用字元，自動包含所有子資料夾
>
> ```toml
> members = ["*"]
> ```
